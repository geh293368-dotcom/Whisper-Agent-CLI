# 听录 TINGLU 轻量品牌规范

状态：发行版工作品牌，尚未完成商标审查与 Partner Center 名称预留  
记录日期：2026-07-13

## 1. 品牌定位

听录是一款 Windows 本地语音转文字与字幕工作台。首版品牌表达聚焦三个已经成立的事实：

- 默认在本机完成语音转录；
- 支持文件、批量任务和麦克风入口；
- 输出可继续使用的 SRT、VTT 和文本结果。

品牌语气应当可靠、清晰、克制。避免使用“零错误”“绝对隐私”“全球最快”“官方 Whisper”等未经验证或容易造成误解的表述。

## 2. 标准名称

品牌核心在所有语言中保持一致，不为每种语言重新设计 Logo。

| 场景 | 主标识 | 功能副标题 |
|---|---|---|
| 简体中文 | `听录` | `本地语音转文字` |
| 英语 | `TINGLU` | `Local Transcription Studio` |
| 其他语言 | `TINGLU` | 未来仅翻译功能副标题 |

正文首次出现可以写作“听录 TINGLU”，后续按界面语言使用“听录”或 `TINGLU`。仓库、命名空间和 `%LOCALAPPDATA%\WhisperDesktop` 暂时保留开发代号，不属于用户可见品牌。

## 3. 一句话

- 中文：`让音视频在本机变成可用字幕。`
- 英文：`Turn audio and video into usable text on your PC.`

一句话用于商店短描述、关于页和网站首屏，不永久画入应用图标。

## 4. 图标概念

图标使用一条连续的“转录线”：起点是简化声波，线条经过一次克制的转折，终点收束为文本光标或字幕行。这个符号同时表达：

1. 听见声音；
2. 在本机完成转录处理；
3. 得到结构化文字。

允许轻微几何变形来建立记忆点，但必须保持简单轮廓和小尺寸辨识度。首轮不使用写实麦克风、播放三角、耳机、云朵、机器人头像或类似 OpenAI 结形图案。

图标本体不包含“听录”或 `TINGLU` 文字。Windows 应用图标需在 16、24、32、48、64、128 和 256 像素下单独检查，不能只看大图。

## 5. 标准字

### 中文标识

- 固定文字：`听录`；
- 使用简洁现代的无衬线结构；
- 可以在“听”与“路”的局部横笔或点画中复用图标的路径转折；
- 变形只作为识别细节，不牺牲第一眼可读性。

### 英文标识

- 固定文字：`TINGLU`；
- 默认使用全大写几何无衬线；
- 字距略宽，适合 Windows 标题栏、商店卡片和关于页；
- `T` 或 `G` 可吸收一次路径转折，但不同时改造多个字母。

生成式图片中的标准字只用于方向评审。正式发行前应根据选定方向重绘为 SVG，并人工检查中文字形和英文字距。

## 6. 基础颜色

| 角色 | 色值 | 用途 |
|---|---|---|
| 深海军蓝 | `#0E1B2A` | 主文字、深色背景、稳定感 |
| 路径青绿 | `#1CB5A3` | 图标主色、选中与进度强调 |
| 雾白 | `#F7FAFC` | 浅色背景、反白标识 |
| 石板灰 | `#64748B` | 副标题、辅助信息 |

Logo 默认使用单色或“深海军蓝 + 路径青绿”双色。应用图标不使用复杂渐变、玻璃高光、3D 挤压和细碎阴影。

## 7. 组合规则

保留三种正式组合：

1. 独立图标：任务栏、桌面、MSIX、favicon；
2. 图标 + `听录`：中文启动页、中文商店素材；
3. 图标 + `TINGLU`：英文启动页、英文商店素材。

功能副标题与主标识分开排版，可以随语言更换。图标四周至少保留图标线宽两倍的安全空间，不拉伸、不旋转、不加外发光，不在低对比度照片上直接使用。

## 8. 当前资产与生成流程

当前已经形成以下可直接使用的栅格资产：

```text
docs/brand-assets/tinglu-brand-board-v2.png
docs/brand-assets/exports/tinglu-icon-1024.png
docs/brand-assets/exports/Tinglu.ico
docs/brand-assets/exports/png/tinglu-icon-{16,20,24,32,40,48,64,128,256}.png
```

`Tinglu.ico` 是包含九个分辨率帧的 ICO 容器，不是只把单张 PNG 改扩展名。1024 PNG 保留透明角，供后续商店素材、安装包和设计调整使用。

使用以下命令可以从当前品牌板重新生成全部尺寸，并同步更新 Web 与 WPF 资源：

```powershell
Tools\build-brand-assets.ps1
```

应用当前使用方式：

- WPF EXE 通过 `ApplicationIcon` 使用多尺寸 `Tinglu.ico`；
- 侧栏和关于页使用 256 PNG 图标；
- “听录”和 `TINGLU` 使用 HTML 真文字排版，便于无障碍、缩放和本地化；
- 原始整张品牌板不直接嵌入关于页，避免白底、固定比例和深色模式问题。

仍需在正式商店提交前完成：

- 根据选定图形重绘 SVG/矢量母版，消除生成图边缘中的细微高光；
- 补充 MSIX Store Logo、Square150x150Logo、Square44x44Logo 等包素材；
- 检查浅色、深色和高对比度版本；
- 完成名称预留与基础商标检查。
