# AI UI 资产切图工具需求草案

状态：需求草案  
用途：未来独立项目立项参考  
适用场景：游戏 UI、图标板、AI 生成 UI 概念图、按钮/面板/组件切图  
记录日期：2026-06-21

## 1. 背景

AI 图像模型可以快速生成一整张 UI 概念图、图标板、技能图标集、按钮组件图或游戏界面风格稿。但这些图片不能直接进入游戏项目或应用项目，需要进一步拆解成单独资源。

这个需求的核心是做一个独立工具：把 AI 生成的大图自动识别、裁切、命名、整理，并导出为可被 Unity、Unreal、Godot、Web 或其他项目使用的 UI 资产包。

这个工具不应该绑定在某个具体项目里。它更适合作为通用“AI 美术资产生产工具链”的一部分。

## 2. 核心目标

工具需要完成以下工作：

1. 导入 AI 生成的大图、图标板或 UI 概念图。
2. 自动识别图中的图标、按钮、面板、滑块、状态徽章等 UI 元素。
3. 将识别出的元素裁切为独立图片。
4. 自动为每个切片起语义化名称。
5. 输出资源元数据，记录类型、状态、尺寸、原图位置和标签。
6. 提供人工复核界面，允许改名、删除、重裁、合并或调整切片。
7. 批量导出 PNG/WebP 和 `metadata.json`。

## 3. 推荐工具链

最稳妥的路线不是完全依赖大模型切图，而是把图像算法和视觉大模型结合起来：

```text
AI 生成图
  -> OpenCV 检测轮廓、透明区域、网格或候选矩形
  -> 裁切候选资源
  -> 视觉大模型识别切片内容和用途
  -> 自动命名和分类
  -> 人工复核
  -> 导出图片资源 + metadata.json
```

说明：

- `OpenCV` 适合做位置检测、轮廓检测、透明背景分析、网格裁切和边界框处理。
- 视觉大模型适合判断“这是什么图标”“这个按钮是什么状态”“这个组件应该叫什么名字”。
- `OpenCC` 不是这个方向的核心工具。OpenCC 主要用于中文简繁转换；图像识别和切图更常用的是 OpenCV。

## 4. 两种切图模式

### 4.1 规则网格模式

规则网格模式适合图标板、技能图标板、道具图标板。

推荐生成图像时就约束模型：

```text
8x8 icon sheet, transparent background, each icon centered in a 256x256 cell,
32px padding, consistent blue sci-fi game UI style
```

特点：

- 最容易自动裁切。
- 不需要复杂识别位置。
- 可以直接按行列切图。
- 适合作为 MVP 第一阶段。

参数：

- 行数、列数。
- 单元格宽高。
- 外边距。
- 单元格间距。
- 是否自动去透明边。
- 是否统一输出尺寸。

### 4.2 自动识别模式

自动识别模式适合整张 UI 概念图，例如一张游戏背包界面、设置面板、技能栏、角色面板。

工具需要自动找出：

- 图标。
- 按钮。
- 面板。
- 滑块。
- 进度条。
- 边框。
- 状态徽章。
- 装饰组件。

特点：

- 更通用，但难度更高。
- 需要轮廓检测、颜色分割、透明区域分析、矩形合并和人工复核。
- 不适合作为第一版唯一能力。

建议：

- MVP 先做网格裁切。
- 第二阶段做自动识别候选框。
- 第三阶段做可视化人工调整。

## 5. 游戏 UI 与网页 UI 的差异

网页项目里很多组件可以用 CSS 或代码实现，不需要切图：

- 普通按钮背景。
- 下拉框。
- 输入框。
- 卡片边框。
- 表格线。
- 开关。
- 简单滑块。

但游戏项目里很多 UI 元素需要真实图片资源：

- 技能图标。
- 道具图标。
- 装备图标。
- 背包格子。
- 圆形按钮。
- 长按钮。
- 面板背景。
- 弹窗边框。
- 进度条底图。
- 进度条填充图。
- 滑块轨道。
- 滑块手柄。
- 选中框。
- 禁用态。
- 高亮边框。
- 品质边框。
- 货币图标。
- 装备槽。
- 九宫格面板，也就是 9-slice。

因此，这个工具更偏游戏美术资产生产，而不只是网页图标裁切。

## 7. 自动命名规则

切片命名是核心能力之一。推荐采用语义化英文文件名，方便程序引用。

示例：

```text
icon_sword_fire.png
icon_inventory_bag.png
icon_currency_gold.png
button_primary_normal.png
button_primary_pressed.png
button_primary_disabled.png
panel_dialog_9slice.png
slider_volume_track.png
slider_volume_thumb.png
badge_success.png
frame_item_rare.png
slot_equipment_weapon.png
progress_hp_fill.png
progress_hp_track.png
```

推荐命名结构：

```text
类别_对象_状态/用途.png
```

常见类别：

- `icon`
- `button`
- `panel`
- `frame`
- `slot`
- `badge`
- `slider`
- `progress`
- `tab`
- `toggle`
- `decoration`

常见状态：

- `normal`
- `hover`
- `pressed`
- `disabled`
- `selected`
- `active`
- `inactive`
- `warning`
- `error`
- `success`

## 8. 元数据格式

每次导出时建议生成 `metadata.json`，记录切片来源和语义信息。

示例：

```json
{
  "source": "ui_sheet_001.png",
  "generatedAt": "2026-06-21T11:30:00+08:00",
  "items": [
    {
      "file": "button_primary_normal.png",
```

## 9. 人工复核界面

完全自动切图容易误判，因此工具需要人工复核。

推荐界面：

- 左侧显示原始大图。
- 在原图上显示自动识别框。
- 右侧显示切片列表。
- 每个切片显示预览、名称、类型、状态、尺寸。
- 支持改名。
- 支持删除。
- 支持重新裁切。
- 支持合并多个切片。
- 支持调整边界框。
- 支持批量导出。

基本操作：

- 框选一个新切片。
- 拖动调整边界。
- 一键去透明边。
- 一键扩展安全边距。
- 一键统一尺寸。
- 一键按网格重切。

## 10. MVP 版本建议

第一版不要做太大，先解决最稳定的场景。

### MVP 功能

1. 导入一张图片。
2. 选择切图模式：网格切图 / 自动检测。
3. 网格切图支持行列、间距、边距配置。
4. 自动检测支持透明背景和明显轮廓。
5. 生成切片预览。
6. 调用视觉大模型为切片命名。
7. 支持人工改名。
8. 导出 PNG + `metadata.json`。

### MVP 暂不做

- 完整游戏 UI 编辑器。
- 复杂九宫格自动判断。
- 全自动无人工复核。
- Unity/Unreal 直接导入插件。
- 批量风格重绘。
- 自动补图。

## 11. 技术选型建议

### 桌面工具路线

适合做成 Windows 桌面工具：

- WPF + WebView2 + React。
- Tauri + React。
- Electron + React。

优点：

- 可以处理本地文件。
- 可以预览大图。
- 可以导出目录结构。
- 适合美术工作流。

### 图像处理

推荐：

- OpenCV：轮廓检测、透明区域分析、边界框、网格切图。
- Sharp 或 ImageSharp：裁切、缩放、格式转换。
- Python Pillow：快速脚本原型。

### 大模型识别

可用能力：

- 视觉模型识别切片内容。
- 给切片生成英文文件名。
- 给切片分类：icon、button、panel、slot、badge 等。
- 生成标签。

注意：

- 大模型负责语义，不负责像素级精确裁切。
- 精确裁切仍应由图像算法和人工复核保证。

## 13. 后续路线

### P0：网格切图工具

- 导入图片。
- 网格切图。
- 自动去透明边。
- 手动命名。
- 导出 PNG。

### P1：AI 自动命名

- 切片后调用视觉大模型。
- 自动生成名称、类型、标签。
- 输出 `metadata.json`。
- 人工复核和批量改名。

### P2：自动识别 UI 元素

- OpenCV 自动检测候选框。
- 支持按钮、面板、图标、滑块、状态徽章。
- 支持合并和调整候选框。

### P3：游戏项目适配

- Unity 资源命名规范。
- Unreal 资源命名规范。
- 9-slice / nine-patch 边距标注。
- 图集打包。
- 多分辨率导出。

## 14. 结论

这个需求应该独立成一个通用工具，而不是某个具体应用的附属功能。

最可行的切入点是：

```text
图标板网格裁切 + 自动命名 + 人工复核 + PNG/JSON 导出
```

等这个链路稳定后，再扩展到：

```text
整张游戏 UI 概念图自动识别切片
```

这个工具未来可以服务多个项目，包括游戏 UI、App 图标、网页图标、技能图标、道具图标、按钮组件和完整 UI 风格稿拆解。
