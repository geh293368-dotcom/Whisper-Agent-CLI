# 批量字幕页面设计图评估

![批量字幕设计图](../../images/design-concepts/batch-concept.png)

## 页面定位

批量字幕页是主工作台。它应该承载导入素材、扫描时长、选择任务、转写进度、字幕预览、AI 优化和最终导出。设计图的方向是正确的：把“导入、队列、预览、输出设置、主操作”放在同一个工作面，而不是让用户在多个页面之间来回跳。

## 页面分块

### 1. 左侧深色导航栏

设计图结构：

- 顶部品牌：声波 Logo、产品名、本地 AI 字幕工作台或版本号。
- 主导航：批量字幕、实时字幕、模型与设置、关于。
- 次级入口：任务中心、日志、帮助与反馈。
- 底部系统状态：状态点、就绪/运行中。

评估：

- 品牌区和主导航值得保留。
- “任务中心”当前不建议保留。批量页的任务队列本身就是任务中心；只有未来存在跨页面后台任务、历史批次、导出队列时才需要。
- “日志”可以先不做独立页面，因为当前批量页已有运行日志 Tab 和打开日志目录。
- “帮助与反馈”可以以后再做，不属于 P0。

### 2. 顶部标题和导入操作

设计图结构：

- 标题：批量字幕。
- 描述：导入音视频文件，使用本地模型批量生成字幕。
- 右侧按钮：导入文件、导入文件夹。

现有能力：

- 已有 `addFiles` 和 `addFolder`。
- 已有 `isScanningMedia` 表示扫描中。

建议：

- 保留这个结构。
- 导入文件和导入文件夹应该始终放在页面右上角，属于页面级主入口。
- “扫描完成”可以由 `sources.length > 0 && !isScanningMedia` 推导，不需要 P0 新增字段。

### 3. 来源文件 / 来源目录卡

设计图结构：

- 显示当前导入路径。
- 更改文件夹按钮。
- 文件数量、总时长、总大小。
- 扫描完成状态。

现有能力：

- 已有来源目录 `sources`。
- 已有任务 `jobs`。
- 已有总时长 `batchStatistics.totalDurationSeconds`。
- 总大小当前只在日志里有计算，不一定作为前端状态发布。

建议：

- P0：保留来源目录列表，不强求只显示单一文件夹。
- P1：新增总大小字段或从 job 文件大小扩展前端状态。
- “更改文件夹”可以等价于“添加/替换来源”，但需要明确是追加还是清空重选。

### 4. 任务队列卡

设计图结构：

- 表格列：勾选、文件名、时长、大小、状态、进度、输出状态、操作。
- 右上角：开始处理、暂停、清空。
- 行内：打开目录、删除。

现有能力：

- 已有勾选、文件名、相对路径、时长、状态、进度。
- 已有开始、停止、清空、移除。
- 当前没有暂停/恢复。
- 当前没有前端显示文件大小、输出状态、行内打开目录。

建议：

- P0：表格视觉可向设计图靠拢，但不要加入“暂停”假按钮。
- P0：主按钮建议保留“开始转录 / 停止”，清空放弱按钮。
- P1：增加输出状态列，例如未开始、生成中、已生成、失败。
- P1：增加文件大小列，前提是宿主发布文件大小。
- P2：暂停/恢复需要批处理状态机，不建议现在做。

### 5. 输出设置卡

设计图结构：

- 输出目录。
- 字幕格式。
- 编码格式。
- 时间戳格式。
- 生成双语字幕文件。
- 同时生成纯文本文件。
- 高级选项。

现有能力：

- 已有输出格式。
- 已有输出位置。
- 已有输出目录。
- 没有编码格式选择。
- 没有时间戳格式选择。
- 没有双语字幕。
- 可以导出 TXT，但不是“同时生成纯文本”的独立批量策略。

建议：

- P0：继续展示输出格式、输出位置、输出目录。
- P1：可以加入“同时导出 TXT”作为独立输出策略，但需要宿主批处理生成多格式。
- P2：双语字幕必须单独设计，不要简单加复选框。双语字幕需要决定：原文+译文双行、两个独立文件、还是 SRT 中同条字幕两行。
- 编码格式和时间戳格式暂不优先，当前 UTF-8/SRT 默认足够。

### 6. 字幕预览卡

设计图结构：

- 标题显示当前文件。
- 刷新预览。
- 打开字幕文件。
- 表格列：序号、开始时间、结束时间、字幕内容。

现有能力：

- 已有 `segments` 预览。
- 已有日志 Tab。
- 暂无“打开字幕文件”按钮。

建议：

- P0：保留预览表格，把当前文件名显示得更明确。
- P1：新增打开当前字幕文件或打开输出目录命令。
- “刷新预览”如果没有真实重新读取文件逻辑，先不要加。

### 7. 底部状态和主操作条

设计图结构：

- 左侧状态：处理引擎、当前模型、语言。
- 右侧主操作：AI 优化字幕、导出全部。

现有能力：

- 已有 `selectedEngine`。
- 已有 `modelStatus` 和 `modelPath`。
- 已有 `selectedLanguage`。
- 已有 `startAiSubtitleOptimization`。
- 没有统一“导出全部”命令，批处理本身会输出文件。

建议：

- 强烈建议吸收这个设计。底部状态条可以统一显示“当前引擎 / 模型 / 语言 / AI Provider / 输出策略”。
- “AI 优化字幕”作为主按钮合理。
- “导出全部”如果只是打开输出目录，按钮文案应是“打开输出目录”；如果要打包导出，需要新功能。

## 建议路线

P0：

- 按设计图重排批量页布局。
- 底部状态条显示引擎、模型、语言、AI 状态。
- 来源区显示扫描状态、文件数量、总时长。
- 主操作只保留真实能力：开始、停止、AI 优化、清空。

P1：

- 文件大小、输出状态、打开字幕文件。
- 同时输出 TXT 策略。
- 完成提示音。

P2：

- 暂停/恢复。
- 双语字幕。
- 打包导出全部。
